# Code-generated videos

All videos in this folder are created from animation code, not from a video-generation model.

- `briefs/`: approved briefs and scripts.
- `src/`: HTML/CSS/JavaScript/SVG/Canvas source.
- `assets/`: rights-cleared local assets.
- `renders/`: MP4 outputs and poster frames.
- `qa/`: render checks, captions, sources, rights notes, and approvals.

Claude-4 Motion Code Lab writes the source. Manus-1 reviews and renders it. MiniMax-1 is limited to thumbnail/cover-frame support and visual QA. Manus-4 prepares upload drafts. Saksham approves publishing.
