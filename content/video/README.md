# Code-generated videos
All videos here are created from animation code, not from a video-generation model. **Only Google-3 / GA-03 (Gemini Argon Motion Code Lab) may write or modify the animation source.**
- `briefs/`: approved briefs and scripts.
- `src/`: GA-03-authored HTML/CSS/JavaScript/SVG/Canvas source.
- `assets/`: rights-cleared local assets.
- `renders/`: MP4 outputs and poster frames.
- `qa/`: render checks, captions, sources, rights notes, and approvals.

MN-03 prepares the editorial brief. GA-03 writes source code. MN-01 may inspect/render but must not edit source. GitHub Actions renders. MM-01 handles visual QA. MN-04 prepares publishing drafts. Saksham approves publishing.
