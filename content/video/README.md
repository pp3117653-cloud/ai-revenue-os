# Code-generated videos
All videos in this folder are created from animation code, not from a video-generation model.
- `briefs/`: approved briefs and scripts.
- `src/`: HTML/CSS/JavaScript/SVG/Canvas source.
- `assets/`: rights-cleared local assets.
- `renders/`: MP4 outputs and poster frames.
- `qa/`: render checks, captions, sources, rights notes, and approvals.

Google-3 Audience and Editorial Desk researches the topic and prepares the approved script and brief. Manus-1 Automation and Demo Builder writes the animation source and verifies it; GitHub Actions renders the video. MiniMax-1 handles thumbnail/cover-frame support and visual QA. Manus-4 prepares publishing drafts. Saksham approves publishing.
