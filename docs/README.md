# CEO Dashboard

This static dashboard is part of the repository and is designed for GitHub Pages. It uses no paid frontend framework, database, or runtime. It stores only local draft metrics/tasks in browser localStorage and opens prefilled GitHub Issue drafts for task assignment.

The repository name is currently configured in `app.js` as `pp3117653-cloud/ai-revenue-os`; update that value if the final repository name differs.

Enable Pages in GitHub repository settings using `main` branch and `/docs` folder. The expected free URL is:

`https://pp3117653-cloud.github.io/ai-revenue-os/`

The dashboard must never contain secrets, client personal data, or production tokens.
